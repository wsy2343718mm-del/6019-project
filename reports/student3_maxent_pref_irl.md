## 2. 最大熵 IRL

### 2.1 动机：模糊性问题

经典 IRL 方法（LP-IRL、MM-IRL）受**奖励模糊性**困扰：许多奖励函数可以解释相同的专家行为。MaxEnt-IRL（Ziebart 等, 2008）通过选择满足专家特征期望的**最大熵轨迹分布**来解决这个问题。这产生了与数据一致的最不偏committed的奖励分布。

**最大熵原理**：在所有满足特征匹配约束的分布中，选择熵最大的那个：

$$P^* = \arg\max_P H(P) \quad \text{s.t.} \quad \mathbb{E}_P[\phi(\tau)] = \mu_E$$

### 2.2 轨迹分布

MaxEnt-IRL 对轨迹 $\tau = (s_0, a_0, s_1, a_1, \ldots, s_T)$ 的概率建模为：

$$P(\tau | \theta) = \frac{1}{Z(\theta)} \exp\left(\sum_{t=0}^{T} \gamma^t R(s_t)\right) \cdot P(s_0) \prod_{t=0}^{T-1} P(s_{t+1}|s_t, a_t)$$

其中：
- $R(s) = \phi(s)^\top \theta$ 是参数化奖励
- $Z(\theta) = \sum_\tau \exp(\text{reward}(\tau))$ 是配分函数
- 转移动力学 $P(s'|s,a)$ 已知

### 2.3 软值迭代

MaxEnt-IRL 的核心创新是**软 Bellman 回溯**，它将标准的 $\max$ 算子替换为 $\text{softmax}$：

**软 Q 函数**：
$$Q_{soft}(s, a) = R(s) + \gamma \sum_{s'} P(s'|s, a) V_{soft}(s')$$

**软 V 函数**：
$$V_{soft}(s) = \text{softmax}_a Q_{soft}(s, a) = \log \sum_a \exp(Q_{soft}(s, a))$$

这产生了一个**随机策略**：
$$\pi(a|s) = \frac{\exp(Q_{soft}(s, a))}{\sum_{a'} \exp(Q_{soft}(s, a'))}$$

**与硬值迭代的关键区别**：
- 硬 VI：$V(s) = \max_a Q(s, a)$ → 确定性策略
- 软 VI：$V(s) = \log \sum_a \exp(Q(s, a))$ → 具有熵的随机策略

### 2.4 梯度计算

关于 $\theta$ 的对数似然梯度为：

$$\nabla_\theta \mathcal{L} = \mu_E - \mathbb{E}_{P(\tau|\theta)}[\phi(\tau)] = \mu_E - \sum_s D(s) \phi(s)$$

其中 $D(s)$ 是当前软策略下的**折扣状态访问频率**：

$$D = D_0 (I - \gamma P^{\pi})^{-1}$$

其中 $P^{\pi}_{ss'} = \sum_a \pi(a|s) P(s'|s, a)$ 是软策略诱导的转移矩阵。

### 2.5 算法步骤

```
初始化：θ = 0
For 迭代 = 1, ..., N:
    1. 计算奖励：R(s) = φ(s)ᵀθ
    2. 软值迭代 → V_soft, Q_soft, π_soft
    3. 计算软策略转移：P^π
    4. 求解状态访问：D = D₀(I - γP^π)⁻¹
    5. 计算梯度：∇θ = μ_E - D·Φ
    6. 更新：θ ← θ + α·∇θ（带梯度裁剪和学习率衰减）
```

### 2.6 数值稳定性措施

MaxEnt-IRL 由于指数项容易出现数值不稳定。我们实现了多项保护措施：

**1. Softmax 数值技巧**：
$$\text{softmax}(x) = \frac{\exp(x - \max(x))}{\sum \exp(x - \max(x))}$$
这通过居中指数的方法防止溢出。

**2. 梯度裁剪**：
$$\nabla_\theta \leftarrow \text{clip}(\nabla_\theta, -0.05, 0.05)$$
这防止可能导致优化不稳定的大梯度步。

**3. 学习率衰减**：
$$\alpha_t = \frac{\alpha_0}{1 + 0.05 \cdot t}$$
这通过随迭代减少步长确保收敛。

### 2.9 软值迭代与硬值迭代对比

| 性质 | 硬 VI | 软 VI |
|------|-------|-------|
| Bellman 回溯 | $\max_a Q(s,a)$ | $\log\sum_a \exp(Q(s,a))$ |
| 策略 | 确定性（$\arg\max$） | 随机性（softmax） |
| 熵 | 0（零熵） | >0（正熵） |
| 鲁棒性 | 对奖励噪声敏感 | 更鲁棒（平滑） |
| 探索 | 无（贪婪） | 内置（softmax 探索） |

- **高熵**：在决策点附近（多个动作具有相似 Q 值）
- **低熵**：在目标或障碍物附近（最优动作明确）

## 3. 基于偏好的学习（Bradley-Terry）

### 3.1 动机：从偏好中学习

虽然 MaxEnt-IRL 从完整演示（状态-动作序列）中学习，但基于偏好的学习只需要**成对比较**："轨迹 $\tau_i$ 比轨迹 $\tau_j$ 更好"。这在许多设置中更自然：

- 人类发现比较两种行为比演示最优行为更容易
- 在机器人学习中，执行演示可能成本高昂，但评判预记录的轨迹很便宜
- 偏好数据可以从非专家用户收集

### 3.2 Bradley-Terry 模型

Bradley-Terry 模型（Bradley & Terry, 1952）定义轨迹 $\tau_i$ 优于 $\tau_j$ 的概率为：

$$P(\tau_i \succ \tau_j) = \sigma(R(\tau_i) - R(\tau_j)) = \frac{1}{1 + \exp(-(R(\tau_i) - R(\tau_j)))}$$

其中 $R(\tau) = \sum_{t=0}^{T} \gamma^t R(s_t)$ 是轨迹的累积折扣奖励。

### 3.3 长度归一化的轨迹特征

偏好学习中的一个关键问题是**轨迹长度偏差**：较长的轨迹自然累积更多奖励，这可能使学习产生偏差。我们通过按长度归一化轨迹特征来解决这个问题：

$$\tilde{\phi}(\tau) = \frac{1}{T} \sum_{t=0}^{T} \gamma^t \phi(s_t)$$

这确保奖励比较基于**每步平均质量**而非总累积奖励。

### 3.4 优化目标

给定 $N$ 个偏好对 $\{(i_k, j_k), y_k\}_{k=1}^N$，其中 $y_k \in \{0, 1\}$，我们最大化对数似然：

$$\max_\theta \sum_{k=1}^N \left[ y_k \log P(\tau_{i_k} \succ \tau_{j_k}) + (1-y_k) \log P(\tau_{j_k} \succ \tau_{i_k}) \right]$$

这等价于最小化**二元交叉熵损失**：

$$\mathcal{L}(\theta) = -\frac{1}{N} \sum_{k=1}^N \left[ y_k \log \sigma(\Delta_k) + (1-y_k) \log(1 - \sigma(\Delta_k)) \right]$$

其中 $\Delta_k = R(\tau_{i_k}) - R(\tau_{j_k})$。

### 3.5 梯度计算

对数似然关于 $\theta$ 的梯度为：

$$\nabla_\theta \mathcal{L} = \frac{1}{N} \sum_{k=1}^N (y_k - \sigma(\Delta_k)) \cdot (\tilde{\phi}(\tau_{i_k}) - \tilde{\phi}(\tau_{j_k}))$$

这直觉上是：预测误差 $(y_k - \sigma(\Delta_k))$ 乘以两个轨迹之间的特征差异。

### 3.6 优化算法

```
初始化：θ = |φ(目标)| + 小噪声（目标导向初始化）
For 迭代 = 1, ..., N:
    1. 计算轨迹奖励：R_i = φ(τ_i)ᵀθ
    2. 计算偏好概率：p = σ(R_i - R_j)
    3. 计算梯度：∇θ = (1/N) Σ (y - p) · (φ(τ_i) - φ(τ_j))
    4. 添加目标导向正则化：reg = λ · (φ_目标/|φ_目标| - θ/|θ|)
    5. 更新：θ ← θ + α · (∇θ + reg) / (1 + 0.01·t)
    6. 投影：θ ← max(θ, 0.01)（确保正权重）
```

### 3.7 目标导向正则化

我们实现中的一个关键创新是**目标导向正则化**：

$$\text{reg} = 0.1 \cdot \left(\frac{|\phi(s_{goal})|}{\|\phi(s_{goal})\|} - \frac{\theta}{\|\theta\|}\right)$$

这鼓励权重向量指向与目标状态特征向量相似的方向。直觉是奖励应在目标处最高，提供引导智能体的自然"梯度场"。

### 3.8 权重正性约束

我们在每次迭代强制执行 $w \geq 0.01$。这确保：
1. 奖励函数有清晰的指向目标的梯度（所有特征正向贡献）
2. 学习到的奖励可解释（没有"负重要性"特征）
3. 优化避免负权重抵消正权重的病态解

### 3.9 学习曲线分析

**图引用**：见图 `s3_preference_learning.png` 了解完整的学习曲线分析。

**关键指标**：

| 指标 | 初始值 | 最终值 | 解释 |
|------|--------|--------|------|
| 预测准确率 | ~50%（随机） | 由数据决定 | 高于 50% = 有学习信号 |
| 交叉熵损失 | 0.693（随机） | 由优化决定 | 递减 = 更好的校准 |

**观察结果**：
- 如果最终准确率显著高于 50%，偏好数据包含可学习的信号
- 如果准确率在 50% 附近徘徊，偏好对基本上是随机的（没有判别信息）
- 交叉熵损失对于调优良好的优化器应单调递减

### 3.10 特征缩放

为防止 sigmoid 函数的数值问题（对大输入饱和），我们在内部缩放轨迹特征：

$$\phi_{scaled} = \frac{\phi}{\max(|\phi|) + 10^{-8}}$$

优化后，权重被重新缩回到原始特征空间：
$$w_{final} = \frac{w_{scaled}}{\text{feat\_scale}}$$

## 4. 对比分析：MaxEnt-IRL 与 Preference-BT

### 4.1 奖励场对比

**图引用**：见图 `s3_maxent_pref_rewards.png` 了解并排的奖励热力图。

| 方面 | MaxEnt-IRL | Preference-BT |
|------|------------|---------------|
| 数据来源 | 专家演示（状态-动作） | 成对比较（轨迹对） |
| 监督强度 | 强（完整轨迹） | 弱（二元标签） |
| 样本效率 | 高（500 条轨迹） | 中等（300 对来自 1000 条轨迹） |
| 奖励平滑度 | 平滑（软策略） | 取决于轨迹覆盖 |
| 计算成本 | 高（每次迭代矩阵求逆） | 低（简单梯度） |

### 4.2 理论性质

| 性质 | MaxEnt-IRL | Preference-BT |
|------|------------|---------------|
| 唯一性 | 唯一（最大熵） | 可能有多个最优解 |
| 一致性 | 当 $N \to \infty$ 时一致 | 当 $N \to \infty$ 时一致 |
| 对噪声的鲁棒性 | 中等（梯度裁剪有帮助） | 高（正则化有帮助） |
| 可扩展性 | $O(T \cdot S^3)$ 每次迭代 | $O(T \cdot N^2 \cdot d)$ 每次迭代 |

### 4.3 实际考虑

**MaxEnt-IRL 适用于**：
- 有完整专家演示可用
- 转移模型已知
- 需要原则性的概率解

**Preference-BT 适用于**：
- 只有相对评判可用（例如来自人类）
- 转移模型未知
- 计算效率很重要

## 5. 挑战与解决方案

### 5.1 挑战：MaxEnt 数值溢出

**问题**：softmax 操作 $\exp(Q)$ 对于大 Q 值可能溢出。

**解决方案**：使用数值稳定的 softmax：$\text{softmax}(x) = \exp(x - \max(x)) / \sum \exp(x - \max(x))$。

### 5.2 挑战：矩阵求逆奇异

**问题**：计算 $D = D_0(I - \gamma P^\pi)^{-1}$ 在 $(I - \gamma P^\pi)$ 奇异时可能失败。

**解决方案**：当矩阵求逆失败时回退到 $D = D_0$。实际上，在 $\gamma < 1$ 和随机转移下，矩阵几乎总是可逆的。

### 5.3 挑战：偏好数据低区分度

**问题**：当偏好标签接近 50/50 分配时，数据没有可学习的信号。

**解决方案**：检测此条件（均值标签值在 48%-52% 之间）并回退到目标导向的默认权重。这避免在无信息数据上浪费计算。

### 5.4 挑战：偏好学习中的梯度爆炸

**问题**：轨迹对之间的大特征差异可能产生爆炸梯度。

**解决方案**：
1. 内部特征缩放（除以最大绝对特征值）
2. 正权重投影（$w \geq 0.01$）
3. 学习率随迭代次数衰减

---

## 6. 结论

MaxEnt-IRL 和 Preference-BT 代表了两种根本不同的奖励恢复方法：

1. **MaxEnt-IRL**：提供了原则性的概率框架，通过最大熵解决奖励模糊性。软值迭代产生平滑、鲁棒的奖励场，具有良好校准的状态访问频率。

2. **Preference-BT**：提供了一种灵活的、样本高效的方法，从弱监督（成对比较）中学习。目标导向正则化和长度归一化确保稳定和可解释的奖励恢复。

两种方法都通过解决 IRL 问题的不同方面补充了经典的 LP/MM-IRL 方法（学生 2）：MaxEnt-IRL 通过熵最大化，Preference-BT 通过基于偏好的学习。它们的组合结果为学生 4 的对比实验提供了全面的评估。
